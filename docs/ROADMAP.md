# Roadmap

## H001 — Triaje multi-interfaz
Clasificar y enrutar reportes de forma determinista, sin persistirlos, para su consulta inmediata desde web y terminal.

## H002 — Resumen de incidentes activos
Consultar incidentes activos, incumplimientos de SLA y resultados filtrados por componente desde web y terminal.

## H003 — Ciclo de vida, duplicados y SLA
Registrar incidentes de forma persistente, advertir sobre equivalentes abiertos y auditar su SLA para cualquier instante de referencia.

## H004 — Persistencia relacional y runtime en contenedores
Preparar una ejecución reproducible en contenedores con una base de datos relacional dedicada y una verificación real de conectividad operativa.
